# 对外材料

这里放从 `docs/` 派生的对外沟通材料，不是设计源。设计以 `docs/` 为准，阶段证据以 `stages/` 为准。

## 2026-11-12

- `ale-500-boss-brief.html` 是管理层计划汇报，只展示试点、首批、正式三段任务费，不展示 token 费用和总包价。
- `pilot-expert-profiles.md` 是三条试点的招募画像，用于按画像找人。
- `candidate-cards/` 是三张候选人版 JD 卡片，按 A4 打印，每张一页。
- `build_report.py` 和 `candidate-cards/build_cards.py` 是生成脚本。

HTML 直接用浏览器打开。打印时选 A4、边距无、勾选背景图形。
