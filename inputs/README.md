# 官方输入副本

这份文件回答一件事：`frozen/` 里是什么、为什么只有这一份、怎么证明它没被改过、要动它该怎么动。

## 这是什么

四个官方来源的只读副本，复制于 2026-11-08，时区 Asia/Taipei，用 rsync 保留硬链接和元数据。

| 目录 | 来源 | 文件数 | 大小 | 版本 |
|---|---|---|---|---|
| `01_agents-last-exam` | 旧任务仓库 | 28,444 | 1.5 GiB | HEAD `2e91edd3cd26baa35a38127c90c8e5241dfbe62f` |
| `02_ale` | 新引擎 | 495 | 10 MiB | HEAD `73517c2eb097abe7974e9ec4de9819a02cd0ee81` |
| `03_ale-data` | 官方任务数据包 | 79,070 | 86 GiB | 无 git |
| `04_ale-tasks-base` | 任务模板仓库 | 105 | 520 KiB | HEAD `492249a2ca4b9d74efd3584a90399473c2e928c7` |

普通文件合计 108,114 个。加上三个记录文件 `README_READ_ONLY.md`、`SOURCE_MAP.tsv`、`SYMLINKS.tsv`，共 108,117 个，正好等于哈希清单的行数。

逻辑字节总量 94,086,734,364 字节，等于 87.63 GiB。磁盘占用约 88 GiB，差量来自分配块。

数据包内部，`archive/` 占 36.48 GiB，`task-data-v1.1/` 占 49.66 GiB。

## 为什么只有一份

原来每个官方来源都有两份，一份工作副本，一份只读冻结副本，合计 176 GiB。逐字节比对过，四个来源除 `.git/config` 和 13 个 `.DS_Store` 外没有差异，三个 git 仓库的 HEAD 完全一致。

统一治理后删掉了四份工作副本，只留这一份。理由有三个：它有全量哈希清单，能证明没被改；它是只读的，不会被误改；三个 git 仓库在这里仍可正常读取，`git log` 可用。

工作副本删除后，`stages/s0-baseline/scripts/final_validate.py` 不再能运行，因为它要求两边同时存在。这是本次治理的一个已知代价，已在该阶段说明里记录。

## 怎么校验

```bash
python3 tools/verify_frozen.py
```

清单格式是三列，分别是哈希、字节数、相对路径，用制表符分隔。它不是标准 `sha256sum` 格式，所以不能直接用 `shasum -c`。

2026-11-11 实测结果：108,117 条全部匹配，87.6 GiB，用时 76 秒，退出码 0。这次校验是在目录改名之后跑的，因此同时证明了改父目录名不影响可校验性。

想快速自检可以加 `--limit 500`，只验前 500 条。

## 只读状态

四个目录是 `555`，普通文件是 `444`，数据目录是 `400`，可执行脚本是 `555`，可写路径为零。

这意味着改一个字节需要先 `chmod`。这是有意的，不要为了省事全局放开写权限。

一个例外要知道：跨目录重命名这个目录本身时，需要临时给目录自身加写权限，因为内核要更新目录里的 `..` 项。做法是 `chmod u+w`、`mv`、`chmod u-w` 三步。本次治理就是这样搬的，权限已恢复原状。

## 和原始目录的已知差异

`.git/config` 与原工作副本不同。原因是冻结时记录的是当时的本地路径，跟踪内容与 HEAD 完全一致。

13 个 `.DS_Store` 只存在于已删除的工作副本里，冻结副本本来就没有。

19 个文件的磁盘分配块大于逻辑字节，它们是稀疏文件或压缩文件，逻辑字节完全一致。

25 条符号链接里，22 条指向内部且可解析，2 条指向内部但目标缺失，1 条指向外部且目标缺失。三条断链都在 `tcga_brca_deg_analysis` 任务的 `.venv` 里，不影响任务本身。

## 阶段二需要可写副本时怎么办

不要改这里。复制出去再用。

```bash
mkdir -p work
cp -a inputs/frozen/02_ale work/ale
chmod -R u+w work/ale
```

`work/` 已在忽略列表里。引擎需要安装依赖和改配置时，都在 `work/` 里做，`inputs/frozen/` 保持只读。

## 不要做的事

不要改这里的任何字节。改了全量清单就对不上，阶段 0 和阶段 1 的证据链同时断掉。

不要重命名四个内部目录。清单里的路径写死了 `01_agents-last-exam/` 这类前缀。

不要用 `shasum -c` 校验这份清单。用 `tools/verify_frozen.py`。

不要在 `frozen/` 里创建新的工作文件。要放东西去 `work/` 或 `docs/`。
