# 阶段 0，官方基线

这份文件回答一件事：阶段 0 做了什么、得出什么结论、怎么证明这些结论没被改过。进这个目录先读这一份，其余文件按需查。

## 状态

已完成并验收关闭。冻结时间 2026-11-08，时区 Asia/Taipei。校验结果 41 项检查通过，40 项 PASS、0 项 FAIL、0 项 ERROR、1 项 SKIP。

本仓库只保留本文件。这个阶段的 11 份基线文档、`evidence/` 和 `scripts/` 留在完整工作副本里，不随设计仓库分发。

## 做了什么

把官方的四个仓库和数据包做成只读副本，逐文件算哈希，然后摸清五件事：官方发布集有多少任务、类别怎么分布、新旧任务格式差在哪、运行环境有哪些 provider、现有哪些风险。

## 结论

官方发布集是 122 条任务，13 个行业域。19 条 computing_math 按项目统计口径排除，非 CS 剩 103 条，其中 Linux 71 条、Windows 32 条。全部 122 条在基线上的运行状态都是 NOT_RUN，一条都没有实际运行过。

图形界面相关的任务里，40 条明确需要，73 条明确不需要，9 条状态未知。这 9 条不能当成不需要图形界面处理。

3 条 GPU 任务全部落在 Windows 侧。13 条任务依赖外部服务，分四种形态：5 条本地托管、6 条必须联网、2 条引用公开网页。另有 8 条在官方口径里被排除在纯 Linux 之外，原因是各自的环境限制。

引擎声明了 8 个模型 provider 和 4 个沙箱 provider。沙箱 provider 是 docker、qemu、daytona、orchard。qemu 需要 /dev/kvm，当前服务器不能嵌套虚拟化，所以 Windows 虚拟机路径在这台机器上跑不了。引擎支持 Windows 客户的声明只到代码层面，没有运行证据。

格式方面，新格式是 Harbor 1.4 加 ALE 扩展，task.toml 只要求两个必填字段，任务自带验证脚本。旧格式到新格式的转换器没有随引擎发布，这条链路从来没有真实运行过。

## 怎么复验

```bash
cd stages/s0-baseline
shasum -a 256 -c FINAL_CHECKSUMS.sha256
```

最后一行应当是 65 条全部 OK。这个命令与目录位置无关，整目录搬走后仍然成立。
