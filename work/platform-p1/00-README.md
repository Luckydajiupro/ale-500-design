## 我做的决定

| 编号 | 决定 | 理由 |
| --- | --- | --- |
| D1 | 八个状态加 `void`，共九个 | `void` 处理重复与退出，不计入 500，比删除安全 |
| D2 | 不引入工作流引擎，用固定状态机加代码守卫 | 14 个 domain_code 各一套流程会让回归成本失控 |
| D3 | 交接物是 zip 加快照清单，工程不连平台 | 减少接口耦合，平台停机不影响转换 |
| D4 | 类目差异只进配置：必填项、资产上限、评审角色、风险规则 | 新增类目不改状态机，30 分钟上线 |
| D5 | 单机 Docker Compose，不上集群 | 500 条、峰值 44 人在岗，集群是过度设计 |
| D6 | 许可、隐私、IRB 是阻断字段，不是提示字段 | 事后补许可比事前填贵一个量级 |
| D7 | 风险分层默认规则写进配置，负责人可改阈值 | docs/03 未冻结阈值，平台不替它冻结 |
| D8 | 首批商业分析、神经影像、建筑节能，共 3 条 | 专家 v5 试点安排；一条 high 加两条 medium，够验风险分层与派单；法律 42 条只走 ale-data 导入，不占试点位 |
| D9 | 配额建议给 `agriculture_env` 补 16 条 | 08 草案漏了这个域，不能按 12 类做覆盖；与专家供给 v1 对齐 |
| D10 | 试点 500 GiB，前 100 条升 1 TiB，按 70% 水位升 2 TiB | 中档资产 live 280 GiB，热占用 316 GiB，512 GiB 到 62%；为导出包与快照留量仍升 1 TiB，低档 135 GiB 放得下 |
| D11 | 库内存规范化 JSON，导出 ale-data 包，Harbor 只在工程侧转换 | Harbor 是运行格式，字段随引擎变；存进库会把版本升级变成全库迁移 |
| D12 | 供应方包走 B 路径：导入 → 校验 → 隔离区 → 人工确认 → 转换；A/B 共用同一校验器与 `PACKAGE.json` 边车 | 官方 ale-data 没有 license/provenance，边车补字段又不改数据布局；隔离区让坏包不污染任务表 |
| D13 | 评审不单设岗位，四批每批 22 名核心加 4 名后备，同批人既生产也评审 | 评审负荷 1,175 小时，摊到 22 人是每人每周约 2 小时；另招一批专职评审养不起也用不满 |
| D14 | 派单用固定五步规则排序，不做模型打分；算法版本入库，旧派单不回溯 | 规则可解释、可重放，出了争议能复盘；模型打分在试点期拿不到足够样本 |
| D15 | 评审 SLA 5 个工作日，第 3 天提醒，第 5 天自动改派；每批首周 3 条盲评，10% 双评，错误率 20% 移出 | 22 人兼职评审，没有硬时限就会在批次末尾堆积，改派比催人更可预期 |
| D16 | 四批各 6.5 周，相邻重叠 2 周，2026-12-01 生产、2027-04-15 收工，04-30 交付 | 与专家供给和评测窗口对齐；重叠 2 周让 22 人池的交接不断档 |

## 与仓库现有文档的冲突

1. `stages/s0-baseline/08_coverage_matrix_draft.csv` 漏了 `agriculture_env`，12 类合计 500。本方案显式补 16 条并保持总数 500。这是最需要拍板的一条。
2. `work/platform-p1-design-v0.md` 是八状态，本方案加 `void` 成九状态。理由见 D1，差异要在定稿时合并。
3. `work/recruitment-plan-v0.md` 的首批是法律、神经影像、建筑节能；专家 v5 改为商业分析、神经影像、建筑节能，法律 42 条走供应方导入。本方案按 v5，v0 的绝对日期也改用相对阶段与 docs/06 的决策日期。
4. `docs/02-plan.md` 把阶段 2（技术可行性）排在阶段 3（平台设计）之前。本方案是并行推进，不替代阶段 2。阶段 2 出口仍要三条任务四段全 PASS。
5. `docs/03-quality-and-acceptance.md` 未冻结抽样率与风险阈值。本方案把抽样率做成配置，默认 30%，试点 100%，不替 docs/03 做制度决定。
6. 设计定稿放 `docs/` 还是 `stages/s3-platform/` 尚未定。本方案暂放 `work/platform-p1/`，定稿后建议迁 `stages/s3-platform/` 并保留本目录作为工作稿。
7. `docs/` 的交接合同只写冻结快照，未写 ale-data 包与 Harbor 转换。本方案在 `01` 的 FR-ALE-01..05 与 `02` 第 14 节补上，定稿时要并回 `docs/03-quality-and-acceptance.md`。
8. legal 配额已按 `docs/04-roles-and-decisions.md` 从 36 统一到 42（legal_research 21、litigation 21），social_sciences 从 34 到 28，总数仍 500。Q7 仍未决的是：供应方 42 条包是否全部计入这 42 条，还是替换部分自产任务。
9. 早前的 9 个月工期、32 份合同、28 名核心、62 人签约、3 名专职评审、5 条试点、跨类目首批 30 条，均已作废。以本目录的 W1 到 W4、每批 22 加 4、104 份合同、3 条试点、W1 内首批 30 条为准。旧稿若在 `work/` 其他文件里还有这些数字，以本目录为最新。
