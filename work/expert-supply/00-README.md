# 00 专家供给与生产计划：文件地图、假设、决定与待拍板项

> 本文件是专家供给这一包的地图：包含哪些文件、基于哪些假设、我替项目做了哪些决定、哪些必须由项目负责人拍板、与仓库现有文档哪里不一致。
> 适用：W0 试点、W1-W4 四批生产的专家招募、排产与评审；平台 P1 的字段与评审设计可以引用本文，但本文不写平台代码。标注手册已于 2026-11-13 删除，不再作为试点或生产依据；压测证据同日删除，不再保留；试点包另建，培训材料另写。
> 阅读顺序：先读 `08-revision-2026-11-13.md`，再读本文件。本文件已按 08 改写；若个别表仍残留 v8 数字（W1 01-15、11-27 3/3 PASS、法律转 Harbor、1,073 h），一律以 08 为准，不再作为执行依据。
